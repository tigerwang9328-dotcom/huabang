# 华邦财务中心 V2.0 执行台账

## 目标

依据 `docs/finance/v2.0/roadmap.md`、`design.md` 与 `implementation-plan.md`，完成可核验的 V2.0 实现、只读发布、切换准备和正式开写 Gate；任何外部前置未达成时保留 No-Go，不以代码或部署替代。

## 当前阶段

生产只读发布预检：恢复副本已完成三项新增迁移的升级、降级、再升级和最小权限核验；当前只准备生产只读发布，所有 V2 写 Gate 继续关闭。

## 阶段

### Phase 1：有效计划与当前事实审计

- [ ] 核验当前工作树、提交、迁移图、生产运行态和 Gate。
- [ ] 将 `implementation-plan.md` 每阶段映射为已实现、待实现、外部阻塞或证据不足。
- [ ] 识别下一项可独立实施的 V2.0 缺口并编写失败测试。
- **Status:** in_progress

### Phase 2：会计内核与当前账工作台缺口

- [ ] 先完成 Phase 4.5 的运行时边界：以服务层查询最终期初批次，并把 `draft/review/post/period_close` 的 Gate 判定与“最终、已锁定、覆盖连续”期初余额组合；只读 readiness 必须展示同一拒绝原因。
- [ ] Phase 4.5 测试顺序：先为“所有功能 Gate 均开但期初未锁定仍拒绝”和“最终锁定期初允许继续 Gate 判定”编写失败路由测试；再实现最小服务；随后跑 V2 全套测试。
- [ ] 不在本步编造期初数据、开启任何生产 Gate，亦不把期初余额直接写入总账；真实最终期初仍须在切换窗口按批准数据落库。

- [ ] 通过受限会话、命令幂等、乐观并发和数据库不变量验证。

## 已定决策

| 决策 | 依据 |
| --- | --- |
| 历史金蝶仅写 `fin_history` 并经 `fin_read` 发布 | 用户范围和有效设计 |
| 当前账工作流为草稿、审核、人工过账 | 用户明确决定 |
| V2.0 不做自动草稿、百胜/钉钉正式适配或附件能力 | 有效路线图 |
| 首版权限使用财务角色与超级管理员 | 用户明确决定 |
| 正式切换默认按会计期间边界 | 用户明确决定 |

## 真实外部前置

| 前置 | 当前状态 | 影响 |
| --- | --- | --- |
| 异机或异存储备份与恢复演练 | 未提供目标 | 正式开写 No-Go |
| 最终期初、覆盖连续性、旧系统冻结窗口 | 未获财务事实/窗口 | 正式切换 No-Go |
| 非空生产形态性能数据、真实通知通道 | 未具备 | 正式开写 No-Go |
| 已登录财务与超级管理员浏览器验收 | 未完成 | 生产业务验收不足 |
