# 公开官网图片目录

把真实图片放到这里（文件名固定），公开页面会自动使用；缺图时页面已用渐变占位，不会报错。

建议放置：
- hero.jpg（首屏大图）
- company.jpg（公司形象）
- brand.jpg（品牌故事）
- product-1.jpg / product-2.jpg / product-3.jpg（产品）
- store-1.jpg / store-2.jpg / store-3.jpg（门店形象）
- space-1.jpg / space-2.jpg（公司场地）

路径在 `src/config/publicSite.ts` 中以 `/images/public/xxx.jpg` 引用。
