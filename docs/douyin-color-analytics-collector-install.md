# 抖音颜色分析采集器安装与运行边界

## 安装

1. 在 Chrome 的 Tampermonkey 中创建脚本，将 `tools/douyin-color-analytics-collector.user.js` 全量粘贴并保存。
2. 只确认它匹配 `https://creator.douyin.com/creator-micro/*`，且唯一外联白名单为 `hbreare.com`。
3. 仅在后台 API 已部署、管理员签发短期采集令牌后，进入创作者中心作品详情页，通过油猴菜单输入令牌与当前创作者 ID。脚本会先请求 `collector-config`；只有服务端 schema、最低脚本版本和最大解压分片字节数均兼容时才启用采集。

令牌和创作者 ID 只保存在当前页面内存：刷新、关闭、休眠恢复或账号切换后必须重新输入。脚本不得保存 Cookie、签名 URL、query、验证码或令牌。

## 采集行为

- 仅观察目录页和作品详情页已有的同源请求；不绕过登录、验证码或平台权限。
- 仅保存白名单目录事实及 `analysis_type=1` 留存曲线、`analysis_type=7` 平台跳出曲线值。后者在服务器语义验证前不得作为跳出率报告或排名。
- 队列保存在站点 IndexedDB。达到配置容量的 80% 时停止新增采集；油猴菜单可导出未上传批次或人工放弃。
- 每个上传分片最多 50 条记录，且不超过服务端 `collector-config` 返回的最大解压字节数；已完成分片会保留标记，重复发送由服务端幂等处理。
- 页面隐藏、关闭或卸载时暂停；恢复可见后才会尝试继续。它不是 24 小时无人值守采集程序。

## 上线前浏览器验收

在预生产 API 和真实已登录创作者中心中依次记录：正常详情页曲线捕获、后台标签、系统休眠恢复、断网恢复、HTTP 429、401/403、账号切换、Chrome 重启、缺片恢复与 80% 容量保护。不得在未完成这些记录前启用生产阶段 A。
