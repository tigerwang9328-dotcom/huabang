# 华邦财务中心 V2.1 来源试点计划

> **状态：未来版本，不属于 V2.0 实施授权。** 仅当 V2.0 Contract 完成、对应子账已经实现并通过总账对账后，才可将本计划转为可执行计划。

## 目的

逐来源启用百胜或钉钉的正式适配与自动草稿，绝不让总账先于相应子账产生不可追溯的正式自动凭证。

## 单来源批准门槛

- 对应子账的数据模型、API、页面、权限、审计和子账—总账对账已通过。
- 来源单据的组织、账簿、科目、税额、辅助维度、附件、版本和撤销规则均有书面映射。
- 确定总账—子账关联键、历史补建范围、来源变更处理、异常队列和前向修复方式。
- 财务负责人批准试点账簿、组织、角色、来源范围、回滚方式与首周日对账负责人。

## 试点顺序

1. 仅对批准来源运行 preview 并核对结果。
2. 对单一账簿/组织开启草稿生成；不自动审核或过账。
3. 连续日对账通过后，按 V2.0 已验证的审核和人工过账流程处理。
4. 首周逐日核对来源、草稿、审核、过账、子账、总账、余额和异常队列。
5. 任一差异停止该来源同步，保留历史与审计证据并前向修复。
