# 华邦财务中心 V2 总体路线图

## 单一执行来源

本路线图和同目录的 `design.md`、`implementation-plan.md` 是唯一有效的后续依据。`archive/` 中的文件均已归档，禁止执行。

## 版本范围

| 版本 | 目标 | 可以开写的条件 | 未启用范围 |
| --- | --- | --- | --- |
| V2.0 会计内核 | 账簿、期间、科目/维度、币种、凭证、总账、基础报表、历史金蝶、附件/审计 | 历史与当前账隔离、期初余额锁定、只读发布和开写 gate 全部通过 | 应收应付、银行对账、资产、工资、税务、现金流量表自动分配 |
| V2.1 业务财务 | 费用付款来源、发票、应收、应付、出纳和银行对账 | 每个子账与总账对账为零，独立生产验收通过 | 资产、工资、税务、预算、合并报表 |
| V2.2 专业域 | 资产、折旧、工资、税务、现金流量表自动分配、管理会计/预算/合并报表 | 数据来源、会计政策、对账、权限和回滚各自通过 | 未独立验收的后续扩展 |

页面或 API 不等于完成；未到版本的域必须展示“未启用”，不得提供写入口或模拟数据。

## 数据域和事实源

```text
fin_history  : 金蝶历史凭证分录是历史会计事实源；历史余额仅为核对快照/性能读模型
fin_current  : 当前已过账凭证分录是当前会计事实源；ledger_balance 是可重建读模型
统一查询视图: 按账簿和明确数据范围投影，不能用 UNION ALL 直接相加重叠期间
```

历史范围和当前范围由已批准的 `history_coverage_end_date` 与 `current_book_go_live_date` 决定。当前账起始日必须晚于历史覆盖截止日；任何重叠期间阻断“含历史数据”查询，直至财务负责人明确选择优先账簿并形成审计记录。

## 旧入口兼容矩阵

| 旧入口类型 | V2 只读发布 | V2 开写后 | 最终处置 |
| --- | --- | --- | --- |
| 旧查询 API | 保留只读，标记来源 | 代理至 V2 只读查询或返回废弃提示 | 有明确替代和下线日期后关闭 |
| 旧制单 API | 返回只读/410，不写任何正式账 | 只可调用 V2 草稿服务；无法适配则 410 | 关闭 |
| 旧审核/过账 API | 禁止 | 永久关闭 | 关闭 |
| 旧财务页面 | 仅展示历史/经营分析 | 跳转新页面或明确只读 | 下线前保留跳转 |
| 旧财务表 | 只读核对 | 不得作为正式账写入目标 | 留存至保留期结束 |

只有 V2 `post` 服务可写当前正式总账。禁止双写；旧写路径关闭时间、适配状态和最终下线日期必须登记在发布基线中。

## 发布和恢复边界

生产过程依次为：备份/恢复演练、兼容迁移、只读应用发布、历史暂存导入和发布、期初建账、财务验收、开启制单、开启审核、开启人工过账、Contract 清理。仅写入冻结窗口内可恢复旧备份；发生真实写入后必须先导出并演练重放，超过回退点只允许前向修复。

V2.0 开写前必须确认 RPO、RTO、备份恢复、PITR 能力、发布锁、数据库角色和历史导入角色；任何一项未验证为 No-Go。
