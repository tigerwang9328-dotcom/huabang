## 已确认实施决策

- V2.0 当前账统一执行“草稿 → 财务人员审核 → 人工过账”；旧 `draft -> posted` 实现只作为兼容基线，不得作为新账写入路径。
- 历史金蝶只导入新的 `fin_history`，保留历史标记、来源键与批次；不写回金蝶或既有 ODS/DWD 事实表。
- 附件仅保留历史引用元数据；V2.0 不实现上传、下载、私有桶、版本控制、恶意文件扫描、备份恢复或对象存储。
- V2.0 角色入口暂按财务人员和超级管理员开放；细粒度组织/账簿/字段授权延后，但必须预留服务边界与审计字段。
