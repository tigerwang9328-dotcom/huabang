> 状态：已实现指标策略目录与只读工作台展示；截至 2026-07-29，只有有持久化事实源的指标可报告数值。未接入采集器必须显示“未接入”，不得显示为 `0` 或“正常”。策略中的 `finance-v2-oncall` 只是逻辑通知路由，真实通知通道尚未配置或演练，因此 `notification_configured=false`。

## 数据安全与读取方式

- 接口：`GET /api/v1/finance-center/v2/monitoring/summary`，要求 `finance:center:view`。
- 页面：`/app/finance-center/core-workspace` 的“运行监控与告警 Gate”。
- 指标只包含总数、状态、阈值和运行策略；不得用凭证摘要、科目、交易对手、用户、账号、手机或原始异常文本作为指标标签。
- API 返回的 `availability=unavailable` 是 Gate 失败状态，不是告警已关闭或数值为零。

## 生产开写 Gate

在下列项目全部拥有可用采集器、阈值与一次生产形态告警/关闭演练证据前，`draft_enabled`、`review_enabled`、`post_enabled`、`period_close_enabled` 保持关闭：

1. API 5xx、锁等待、死锁和余额差异；
2. 来源收件箱与异常队列（若仍不在 V2.0 范围，则维持来源同步 Gate 关闭并在证据中标注）；
3. 大账簿分页、单凭证过账 P95、月结、报表并发与导出资源限制的实际测量；
4. 值班通知路由的真实送达、确认与关闭记录。

## 验收记录格式

每次演练记录：UTC 时间、环境、触发的指标、阈值、无敏感标签的截图/响应摘要、收到通知的值班角色、确认时间、关闭时间、关联工单或审计事件。不得在本文件写入密码、Webhook、令牌、Cookie 或真实财务明细。
