# 金蝶历史账簿页面适配设计

## 目标

三套已迁入的金蝶账簿在财务中心中始终只读，并在有已导入来源事实的数据页显示真实历史数据；没有相应来源事实的数据页必须明确说明，不能以零值或模拟数据代替。

## 范围与边界

- 账簿、科目、凭证、分录、余额快照仅从 `finance_center_mumaren` 读取。
- 历史账簿永久只读；不调用创建、审核、过账、删除或补齐期初科目的写接口。
- 不读取或改写旧财务 `fin_*`、华邦旧财务接口或金蝶来源库。
- 已迁入凭证按 `posted` 展示；金额规范化仍以来源标识提示。
- 缺少金蝶导入事实的模块不展示可编辑表单或伪造零数据，而是显示“该类历史来源未迁入”的只读说明。

## 实施设计

1. 以全局账簿选择为唯一上下文；页面切换账簿后取消旧请求，且只提交对应账簿的返回结果。
2. 账簿、科目余额、总账/明细账、凭证、余额快照与可由已过账凭证推导的三张报表，统一使用该账簿 ID 查询。
3. 应收应付和税务仅展示其已有导入的只读记录；无事实记录时使用“未迁入”状态，不显示新增、审核、结算或删除动作。
4. 资产、出纳、发票、工资、费用、销售月报、辅助核算、操作日志等未迁入事实的页面使用统一只读来源缺失状态，并说明其不会影响历史凭证、余额快照及三张报表。
5. 每页在浏览器以三套历史账簿轮换验收；至少验证账簿隔离、只读按钮禁用、数据或来源缺失状态正确。

## 验收

- 所有历史账簿 API 请求都带 `book_id`，且没有跨账簿数据显示。
- 339 张凭证、4,596 条分录和 6,868 条余额快照仍不变。
- 任何历史账簿的写接口返回拒绝；当前普通账簿草稿到审核到人工过账保持可用。
- 前端类型检查、构建、针对性单元测试和浏览器验收均通过。
