# 线上销售菜单归属调整设计

## 目标

将目前侧边栏顶部独立展示的“投流优化”和“经营日报”统一移动到“销售中心 → 线上销售”三级菜单中，使线上经营相关功能集中展示。

## 菜单结构

调整后的“线上销售”子菜单顺序：

1. 投流优化：保留原路径 `/app/marketing/investment`，可点击。
2. 经营日报：保留原路径 `/app/report`，可点击。
3. 线上总览：继续显示“规划中”。
4. 平台销售：继续显示“规划中”。
5. 退款售后：继续显示“规划中”。

侧边栏顶部不再重复展示“投流优化”和“经营日报”。

## 权限与兼容性

- 两个入口随“销售中心”分组展示，使用现有销售中心权限。
- 不修改页面组件、接口、数据采集逻辑和原路由地址。
- 已保存的旧链接继续可用。
- 路由命中时自动展开“销售中心 → 线上销售”，并高亮对应菜单项。

## 验证

- 增加菜单结构测试，确认两个入口只存在于线上销售子菜单。
- 保留投流优化页面和路由测试。
- 运行全部前端测试和生产构建。
- 部署后检查生产构建产物包含两个新菜单入口。
