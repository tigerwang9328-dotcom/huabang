# 财务中心 V2 中台权限接入设计

## 目标

财务中心 V2 不建立独立用户、角色或登录态，统一复用华邦中台的 JWT、`sys.sys_user`、`sys.sys_role`、`sys.sys_permission` 和 `sys.sys_role_permission`。

## 首版授权边界

- `super_admin`：沿用中台管理员旁路，并保留其操作审计身份。
- `finance_manager`：唯一的普通财务角色；由中台角色关系授予。
- `finance:center:view`：查看财务 V2 工作台、历史账、账簿、报表、期间状态和监控摘要。
- `finance:center:operate`：提交 V2 写命令；实际草稿、审核、过账和结账仍由既有 Feature Gate 独立阻断。
- 不实现组织、账簿、维度、字段或导出范围控制；这些不因本次授权而被绕过或伪造。

## 数据流

登录接口继续从中台用户、角色和权限关系返回 JWT 及权限列表。前端路由以 `finance:center:view` 限制财务中心；后端每个 V2 只读端点强制检查该权限，每个 V2 写端点强制检查 `finance:center:operate`。后端还要求非管理员拥有 `finance_manager`，防止其他角色被误配同名权限后获得财务操作资格。

部署时由独立、幂等的权限种子脚本创建缺失的角色和两项权限，并只为 `finance_manager` 补充这两项关系；不修改既有用户、既有角色状态或其他角色的权限。数据库连接账户与用户权限继续分离。

## 验证与回滚

测试覆盖权限常量、非财务角色拒绝、缺少读/写权限拒绝、管理员旁路，以及每条 V2 路由的读写权限依赖。恢复副本中先执行种子脚本并用中台登录接口验证令牌权限，再部署至生产。回滚只移除本次角色-权限关联并恢复前端/后端代码；不删除任何用户或账务事实。
