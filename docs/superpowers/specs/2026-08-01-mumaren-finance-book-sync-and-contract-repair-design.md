# 牧马人财务中心：全局账簿与接口契约修复

## 目标

任一财务中心页面选择账簿后，其他财务页面沿用同一账簿；修复发票、出纳账户与流水、银行调节表、辅助核算的前后端字段不一致；税务录入改为当前账簿税种下拉。

## 设计

新增前端共享账簿组合式状态：持久化最后一次有效账簿 ID，在每个财务页面加载账簿列表后校验有效性；选择变化时更新共享状态并重新加载当前页数据。所有现有账簿选择器绑定该状态，路由与后端账簿隔离继续保留。

将前端 API 类型、页面展示和提交载荷统一到当前后端模型：发票使用 `invoice_no/invoice_type/counterparty_name`；出纳使用 `account_code/currency` 与 `flow_date/in|out/category/counterparty_name`；调节表使用 `cash_account_id/period/adjusted_balance`；辅助核算使用标准维度、`parent_id/is_active`。

后端新增仅按 `book_id` 返回启用税种的读取接口；税务弹窗加载后使用名称和编码下拉选择，提交仍使用该税种 ID。

## 安全与验收

所有写入继续只创建或修改草稿，绝不自动审核、过账或生成凭证。为共享账簿、每个契约修复和税种列表补充先失败后通过的回归测试；运行后端相关测试、前端回归测试和生产构建。生产验证包括跨页选择同一账簿，以及四个报错页正常加载和税种下拉可选。
