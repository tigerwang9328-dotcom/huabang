华邦AI中台项目骨架（企业级菜单架构版）
版本：V1.1
生成日期：2026-07-08
适用范围：华邦AI中台当前生产服务器 /srv/huabang-ai-center

一、调整背景

原侧边栏存在信息架构混乱问题：
1. 一级菜单混入了业务模块、数据源管理、基础档案、技术配置。
2. 商品主档、SKU档案、仓库档案、百胜API管理等三级/后台功能被放到了过高层级。
3. 门店、商品、库存、财务、人事等业务域没有按照企业经营模块组织。
4. 系统看起来像临时后台，不像企业级经营中台。

本次调整目标：
1. 一级菜单只保留企业级业务中心。
2. 二级菜单承载业务模块。
3. 三级菜单承载具体页面、对象或分析维度。
4. 已成熟页面继续保留，不删除原有路由，不影响已有接口。
5. 暂未建设页面以“规划中”禁用项展示，避免跳转不存在页面。

二、新一级菜单架构

一级菜单调整为：
1. 经营概览
2. 销售
3. 商品
4. 采购
5. 库存
6. 财务
7. 人力资源
8. 知识库
9. 系统设置

三、菜单详细结构

1. 经营概览

定位：老板和管理层进入系统后的经营全局入口，承载全局看板、经营日报和任务闭环。
当前页面：
- 经营总览：/app/dashboard
- 经营日报：/app/boss
- 任务闭环：/app/task

保留能力：
- 昨日销售额
- 昨日订单数
- 昨日销售件数
- 客单价
- 件单数
- 折扣率
- 毛利额
- 毛利率
- 库存金额
- 库存风险指标
- 数据资产统计

2. 销售

定位：线下、线上、门店、导购、排行、异常等销售经营分析中心。

当前结构：
- 线下销售
  - 门店总览：/app/store/overview
  - 单店分析：/app/store
  - 会员运营：/app/member
  - 导购销售：规划中
- 线上销售
  - 线上总览：规划中
  - 平台销售：规划中
  - 退款售后：规划中
- 销售异常：/app/warning

说明：
- 原“门店经营”归入“销售 > 线下销售”。
- 门店不再作为一级菜单出现。
- 线上销售暂未接入真实平台数据，先保留规划中入口。

3. 商品

定位：商品主数据、动销、SKU、爆款、滞销、补货、清仓的经营中心。

当前结构：
- 商品总览：/app/product
- 商品主档：/app/product/products
- SKU档案：/app/product/skus
- 动销分析：规划中

4. 采购

六、当前技术架构概况

服务器：hbreare-server
部署目录：/srv/huabang-ai-center
前端：Vue3 + TypeScript + Element Plus + ECharts
后端：FastAPI + Uvicorn
数据库：PostgreSQL，本机 huabang_ai
缓存：Redis，本机 localhost:6379
反向代理：Nginx
远程访问：Tailscale + 阿里云网关入口
百胜接口：本地服务器直连百盛开放平台

七、数据库分层

当前数据库已具备以下分层：
- ods：原始数据层
- dwd：明细清洗层
- dim：维度层
- dws：汇总层
- dm：数据集市层
- app：应用业务层
- ai：AI结果层
- sys：系统配置层
- log：日志审计层
