# 华邦 AI 中台「投流优化」前端生成提示词

你是一名资深 B 端产品设计师和前端工程师。请为华邦 AI 中台设计并实现一个“投流优化”页面。页面服务于本地男装门店经营者，核心任务不是展示漂亮报表，而是把 LifeData 采集到的自然流量、投放消耗、成交、实际核销和退款串起来，明确告诉经营者下一步应该投什么、投多少、投给谁、何时止损。

## 产品目标

1. 用户一眼看清近 7 日投放消耗、广告成交、实际核销、退款，以及成交 ROI 和核销 ROI。
2. 支持按素材、账号、日期、投放场景、年龄、性别、地域、人群和时段查看多维数据。
3. AI 必须给出下一步可执行的投流优化建议，但第一阶段只允许人工确认，不得自动创建或调整投放。
4. 所有结论以“实际核销金额”为最终结果指标；播放量、成交金额只能作为过程指标。
5. 清楚区分“平台广告归因数据”和“账户同期经营数据”。无法精确归因时必须标记为估算，不得伪装成确定结论。

## 页面信息架构

页面顶部提供主体账号、统计周期、数据新鲜度、采集器在线状态和手动刷新。首屏核心指标包含：投放消耗、广告成交金额、实际核销金额、退款金额、广告成交 ROI、实际核销 ROI、单张核销成本。金额统一以元展示，悬停可查看原始分值和指标口径。

首屏右侧设置“AI 下一步建议”决策卡，必须包含：

- 建议动作：加投、维持观察、降低预算或停止；
- 建议对象：明确到素材/视频/计划；
- 建议预算区间和观察周期；
- 建议人群：年龄、性别、地域及人群标签；
- 证据：至少引用 3 个具体数据；
- 止损条件：消耗、核销 ROI、退款率或连续观察时长；
- 置信度和风险说明；
- “人工确认”按钮，按钮文案不得暗示系统已经执行投放。

主体区域至少包含：

1. 投放漏斗：曝光/播放 → 有效播放 → 互动/进店 → 成交 → 实际核销 → 退款。
2. 素材效能：表格与散点图联动，展示播放、5 秒率、完播率、互动、消耗、广告成交、实际核销、退款、成交 ROI、核销 ROI；支持按“值得加投、继续观察、建议停止”筛选。
3. 人群分析：年龄 × 性别交叉对比，展示消耗占比、成交、核销和成本，不要只画消耗分布。
4. 地域分析：贵阳优先，突出云岩区、南明区、观山湖区、白云区；小区级数据存在时展示小区，房价每平方米高于 5,000 元作为业务标签，不得在没有数据时伪造小区或房价。
5. 时间趋势：按日或小时对比消耗、成交、核销、退款和 ROI，支持查看投放后的核销滞后。
6. 建议记录：保留每次 AI 建议、人工确认/驳回、实际投放反馈和后续核销结果，形成学习闭环。

## 数据与状态要求

使用真实 API 数据驱动，禁止把示例数字硬编码为生产结果。设计完整的加载、空数据、部分模块缺失、登录失效、采集器离线和 API 错误状态。部分数据缺失时仍展示可用数据，并明确列出缺失维度和最后成功时间。

可用字段方向包括：`total_ad_cost`、`current_ad_cost`、`total_ad_pay_gmv`、`current_ad_pay_gmv`、`pay_gmv`、`verify_gmv`、`refund_gmv`、`verify_cert_cnt`、视频播放/完播/互动字段、年龄性别消耗、地域消耗和素材排行。派生指标必须在前端或后端统一口径计算，并为除数为 0、负数和缺失值提供明确处理。

## 视觉风格约束

整体风格限定为“克制、专业、高信息密度的经营决策驾驶舱”。以深墨蓝、炭黑、暖白和低饱和灰为基础色；绿色只表示健康增长或建议加投，橙色表示观察，红色表示止损或风险。排版强调数字层级、列对齐和可扫描性，使用清晰的中文无衬线字体。图表减少装饰，坐标、单位、统计周期和口径必须清楚。

不要使用霓虹渐变、玻璃拟态、发光边框、无意义的大面积渐变、悬浮 3D、卡通插画或千篇一律的“每个指标一个圆角卡片”布局。不要为了视觉效果牺牲表格密度和指标可比性。

视觉风格受上述约束，但实现方式不受限制：可以自行选择组件结构、图表库、状态管理、CSS 方案和响应式策略；不要求绑定某个 UI 框架。需要与现有 AI 中台导航和登录体系自然衔接，桌面端 1440px 优先，同时保证 1280px 可用。

## 交付要求

输出可运行的完整前端页面，不只提供静态图片。先说明信息架构和数据映射，再给出实现。组件边界清晰，图表和表格可联动，筛选条件可复用。提供模拟 API 适配层用于本地预览，但与真实 API 接入点分离，并标明需要后端提供的字段。最后列出验收清单，逐项验证多维数据、AI 建议、人工确认、错误状态和响应式布局。
